# Telemetry

Collecting, storing, and visualizing logs, metrics, and traces, along with the supporting infrastructure services it monitors in Docker env.

## Tools

- **Grafana** – dashboards for logs, metrics, and traces
- **Prometheus** – metrics storage and querying
- **Loki** – log aggregation
- **Tempo** – distributed tracing
- **Grafana Alloy** – telemetry collector (Docker logs, OTLP traces, cAdvisor metrics)
- **nginx Prometheus Exporter** – nginx metrics for Prometheus
- **Nginx** – reverse proxy with TLS termination
- **PostgreSQL** – relational database
- **Valkey** – cache / key-value store
- **RustFS** – S3-compatible object storage
